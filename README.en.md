## 👋 What is this?

A **toolbox** with simple, reusable resources about applied AI and Microsoft Copilot,
designed so that **anyone**—with or without a technical background—can copy, adapt, and
use them in their day-to-day work.

> 🌐 **View it on the web:** this repo is published with **GitHub Pages**, so the resources
> are rendered (rather than displayed as code): **https://aespese29.github.io/ia-toolbox/**

---

## 🧭 What will you find here?

| Folder | What it contains |
|---|---|
| 🤖 [`/agentes`](./agentes) | Copilot Studio agent instructions, ready to copy and paste |
| 💬 [`/prompts`](./prompts) | **Prompteca**: a library of reusable prompts organized by task |
| 📚 [`/tutoriales`](./tutoriales) | Step-by-step guides (Copilot, agents, GitHub Pages…) |
| 📦 [`/recursos`](./recursos) | Interactive tools, infographics, and downloadable materials |
| 🎓 [`/sessions`](./sessions) | Materials from webinars and educational sessions |
| 🖼️ [`/assets`](./assets) | Shared images, logos, and styles |

---

## 🚀 How to use it

1. **Browse** the folder that interests you (or visit the website through GitHub Pages).
2. **Copy** what you need: open an interactive tool, or copy an agent's instructions or a prompt.
3. **Adapt it** to your needs. Everything is designed as a starting point, not as a finished solution.

> 💡 No technical background? Start with the [tutorials](./tutoriales) and [Prompteca](./prompts).
