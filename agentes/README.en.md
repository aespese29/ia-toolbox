# 🤖 Agents

[Spanish](README.md) · [English](README.en.md)

Copilot Studio agent instructions, ready to **copy and paste**.
Each agent lives in its own folder with its profile, instructions, and usage examples.

## 📇 Available agents

| Agent | What it does | Level |
|---|---|---|
| [✍️ Copy Master](./copy-master) | Creates advertising copy tailored to each audience, channel, and objective | Basic |
| [🧩 FormatIA](./formatia) | Shapes the instructions for your declarative agents in Markdown | Basic |
| [🚀 M365 Soporte Usuario](./m365-soporte-usuario) | Helps you use Microsoft 365 Copilot and generates ready-to-use prompts | Basic |
| [🎨 Designer Prompt Architect](./designer-prompt-architect) | Turns ideas into detailed visual prompts for Microsoft Designer | Basic |

## ➕ Publish a new agent

1. Create a new folder with the agent's name (lowercase and hyphenated, without accent marks).
2. Add these files inside it:
   - `README.md` → the agent profile (description, features, author).
   - `instrucciones.md` → the instructions, ready to copy and paste.
   - `banner.jpg` → the header image.
3. Add it to the table above.

> 💡 Tip: do not include sensitive data in the instructions, and test the agent
> with a real use case before sharing it.
