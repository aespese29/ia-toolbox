# 🤖 Agentes

Instrucciones de agentes de Copilot Studio, listas para **copiar y pegar**.
Cada agente vive en su propia carpeta con su ficha, instrucciones y ejemplos de uso.

## 📇 Agentes disponibles

| Agente | Para qué sirve | Nivel |
|---|---|---|
| ./formatia | Da forma a las instrucciones de tus agentes declarativos en markdown | Básico |
| ./m365-soporte-usuario | Ayuda a usar Microsoft 365 Copilot y genera prompts listos para usar | Básico |

## ➕ Publicar un agente nuevo

1. Crea una carpeta nueva con el nombre del agente (minúsculas y guiones, sin tildes).
2. Añade dentro estos archivos:
   - `README.md` → la ficha del agente (descripción, funcionalidades, autor).
   - `instrucciones.md` → las instrucciones listas para copiar y pegar.
   - `banner.jpg` → la imagen de cabecera.
3. Añádelo a la tabla de arriba.

> 💡 Consejo: no incluyas datos sensibles en las instrucciones y prueba el agente
> con un caso real antes de compartirlo.
