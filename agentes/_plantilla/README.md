## 🚀 Cómo usarlo
1. Abre Copilot Studio → **Crear agente**.
2. Pega las instrucciones anteriores.
3. Añade fuentes de conocimiento si aplica.
4. Prueba con un caso real, ajusta y comparte.

## ⚠️ Buenas prácticas
- No introduzcas datos sensibles ni confidenciales.
- Verifica las respuestas antes de usarlas en decisiones importantes.
