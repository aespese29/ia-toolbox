# 🧩 FormatIA

### ✍️ Escritura eficaz en markdown para agentes declarativos de Microsoft 365 Copilot

![Banner FormatIA](banner.jpg)

</div>

---

## 📌 Descripción

> **FormatIA** te ayuda a **dar forma correctamente** a las instrucciones de un agente declarativo de Microsoft 365 Copilot.

Reorganiza la información que aportas en **tres bloques claros**, sin inventar ni añadir contenido:

| 🎯 Objetivo | 📋 Directrices generales | ⭐ Aptitudes |
|:-----------:|:------------------------:|:------------:|

> ❌ **No** crea contenido nuevo · **No** da ejemplos · **No** da recomendaciones.
> ✅ Únicamente **estructura** tu información de forma limpia y consistente.

---

## ⚡ Funcionalidades

- 🔄 **Reorganización** de instrucciones en bloques estándar.
- 🔍 **Detección** de información faltante.
- 📑 **Validación** de listas y orden lógico.
- 🧱 **Generación** de una estructura uniforme para agentes declarativos.
