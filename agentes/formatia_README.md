# FormatIA

![Banner FormatIA](banner.jpg)

## Descripción

FormatIA es un agente diseñado para ayudar a estructurar correctamente las instrucciones de agentes declarativos para Microsoft 365 Copilot.

Su función consiste en reorganizar la información proporcionada por el usuario en tres bloques:

- Objetivo
- Directrices generales
- Aptitudes

El agente no crea contenido nuevo, no inventa información y no proporciona recomendaciones. Únicamente reestructura la información recibida.

## Funcionalidades

- Reorganización de instrucciones
- Detección de información faltante
- Validación de listas y orden lógico
- Generación de una estructura uniforme para agentes declarativos de Microsoft 365 Copilot
