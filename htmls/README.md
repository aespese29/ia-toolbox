# 🎨 HTMLs visuales

Piezas HTML listas para abrir en el navegador (o vía GitHub Pages).

- 📈 [`/informes-visuales`](./informes-visuales) — informes con métricas, barras y secciones.
- 🧾 [`/infografias`](./infografias) — infografías de una sola vista.
- 🧱 [`/plantillas`](./plantillas) — bases reutilizables para partir de cero.

## Ejemplos incluidos
- `informes-visuales/ejemplo-informe.html`
- `infografias/ejemplo-infografia.html`
- `plantillas/plantilla-base.html`

> Consejo: nombra los archivos en minúsculas y con guiones. Ej.: `adopcion-copilot.html`.
