# 🖼️ Infografías M365 · IA Toolbox

Sección de la **IA Toolbox** con infografías divulgativas sobre novedades de **Microsoft 365
Copilot** y el ecosistema Microsoft 365, basadas en anuncios del **Centro de mensajes (Message
Center)**.

Cada infografía se publica en tres formatos: **PNG** (para redes), **PDF** (imprimible/compartible)
y **HTML interactivo** (para web).

## 📂 Organización

Una carpeta por infografía, nombrada con el ID de mensaje `MCxxxxxxx`. La **fecha de publicación**
se indica en el README de cada pieza.

```
infografias-m365/
└── MCxxxxxxx-tema/
    ├── *.png   · *.pdf   · *.html
    └── README.md   (ficha + fecha de publicación)
```
