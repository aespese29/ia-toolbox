# 💬 Prompteca · Reusable Prompt Library

[Spanish](README.md) · [English](README.en.md)

A collection of effective prompts organized by task. **Copy, adapt, and use.**

> 💡 A good prompt usually has **4 parts**: role · task · context · format.

## 🗂️ Categories

- 📝 **Writing** — Emails, articles, summaries
- 📊 **Analysis** — Data, information, trends
- 🎨 **Creativity** — Design, visual content, brainstorming
- 🔍 **Research** — Search, synthesis, questions
- 💼 **Productivity** — Organization, planning, methods

---

## 📇 Featured prompts

### 📝 Email draft
```
Act as [role]. Write an email to [audience] about [topic].
Context: [key details]. Tone: [friendly / formal]. Length: max. 10 lines.
Include a clear subject line and a call to action.
```

### 📄 Actionable summary
```
Summarize the following text in 5 key points and provide a task list with an owner
and date if mentioned. Flag anything urgent. Text: [paste here].
```

### 📊 From table to insight
```
Analyze this data and tell me the 3 most relevant trends in plain language,
without formulas. Point out any outliers. Data: [paste table / CSV].
```

### 🎨 HTML infographic
```
Generate the code for an HTML infographic that visualizes this data, with a
modern design, visual cards, and clean typography. Data: [paste here].
```

### 🚀 Structured brainstorming
```
Generate 10 ideas about [topic] from different angles:
1. User perspective
2. Technical perspective
3. Business perspective
4. Innovation perspective

For each idea, add: what, why, how, and potential risks.
```
