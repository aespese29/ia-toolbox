# Planner comes to Copilot Chat (MC1443523)

[Spanish](README.md) · [English](README.en.md)

Microsoft 365 Copilot Chat will let users **create, view, and update Planner tasks and plans
using natural language**, without switching applications. It retains existing permissions and
**requires no action**.

[![Infographic: Planner comes to Copilot Chat (MC1443523)](AE_Infografia_CopilotPlanner_LinkedIn_v01.png)](AE_Infografia_CopilotPlanner_LinkedIn_v01.png)

## ✨ At a glance

- **Create** Planner tasks and plans from Copilot Chat using natural-language prompts.
- **View** task and plan details directly in chat (this release is text-only; an upcoming release
  will include an interactive task card).
- **Manage and update** tasks and plans across Copilot and Planner without switching applications.
- Existing Planner **permissions and access controls** are respected.
