# 🖼️ M365 Infographics · IA Toolbox

[Spanish](README.md) · [English](README.en.md)

An **IA Toolbox** section featuring informative infographics about updates to **Microsoft 365 Copilot** and the Microsoft 365 ecosystem, based on announcements from the **Message Center**.

Each infographic is published in three formats: **PNG** (for social media), **PDF** (for printing/sharing), and **interactive HTML** (for the web).

## 📂 Organization

One folder per infographic, named with the message ID `MCxxxxxxx`. The **publication date** is provided in each item's README.

```
infografias-m365/
└── MCxxxxxxx-tema/
    ├── *.png   · *.pdf   · *.html
    └── README.md   (details + publication date)
```
