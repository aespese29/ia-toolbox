## 🧱 The 6 blocks

1. **Identity** — a name and one-sentence description that activates the skill.
2. **Goal** — what it solves and what result it delivers.
3. **When to use it** — activation cues and when *not* to use it.
4. **Instructions** — the process steps, in order.
5. **Tone and format** — how it should sound and how the result is delivered.
6. **Context and boundaries** — reference data and rules that must not be bypassed.

## 🛠️ How to use it

1. Download the template and rename it to `SKILL.md`.
2. Create a folder named after the skill, using lowercase letters and hyphens.
3. Fill in the six blocks (start with Identity and Goal).
4. Test the skill with a real-world case and adjust the instructions based on what does not work.
