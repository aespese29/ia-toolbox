De los prompts a la productividad

¿Prompt, Agente o Skill?

Elige el enfoque, rellena lo mínimo imprescindible y llévate el artefacto listo para pegar en Copilot. No compiten: el prompt es la petición puntual, el agente es el quién y la skill es el cómo.

1Tres preguntas para decidir

Si no lo tienes claro, responde y te propongo el camino.

¿Lo vas a hacer una sola vez o es exploratorio?

¿Se repite y debe salir siempre igual (misma estructura, mismo tono)?

¿Es un rol completo, con varias tareas, conocimiento propio y gente que lo usa?

Responde las preguntas para ver la recomendación.

El cómo

Skill

El método de una tarea concreta, empaquetado en Markdown y reutilizable.

  • Procesos repetibles
  • Carpeta + SKILL.md obligatorio
  • PowerPoint · Excel · Cowork · Agent Builder

Prompt · instrucción puntual

Úsalo para tareas únicas. Funciona… mientras te acuerdes de todas las reglas.

Qué debes proporcionar: rol, tarea, contexto o fuente, formato de salida y restricciones. Cuanto más explícito seas, menos varía el resultado.
Rellena el formulario y pulsa «Generar prompt».
Señal de alarma: si pegas este texto más de dos veces por semana, ya tienes tu primer candidato a Skill.

Agente · el quién

Un agente nuevo por responsabilidad; una skill por tarea dentro de esa responsabilidad.

Qué debes proporcionar: nombre, propósito, audiencia, instrucciones de comportamiento, conocimiento o fuentes, límites y las skills que invocará (máx. 8 en Agent Builder).
Rellena el formulario y pulsa «Generar instrucciones».
Atajo: «Prompt para Agent Builder» genera el texto en lenguaje natural para crear el agente y sus skills solo hablando.

Skill · el cómo

Escribes el método una vez y lo reutilizas siempre.

Estructura obligatoria: una carpeta con el nombre de la skill que contiene un SKILL.md. El archivo empieza con frontmatter YAML entre --- con los campos obligatorios name y description. Debajo, el método en Markdown. Los recursos (references/, templates/, scripts/) son opcionales y solo si la superficie los admite.
kit-anuncio-evento/ ├─ SKILL.md ← obligatorio ├─ references/guia-estilo.md (opcional) └─ templates/plantilla-kit.md (opcional)
Una skill, una tarea: si necesitas la palabra «y» para describirla, son dos skills.
Empieza por «Usa esta skill cuando…» e indica también cuándo NO usarla.
Rellena el formulario y pulsa «Generar SKILL.md».
Checklist antes de compartir: una skill = una tarea · description precisa (cuándo sí y cuándo no) · dueño y versión · probada con datos ficticios.

4Dónde viven hoy las Skills

La misma skill no se reutiliza automáticamente entre superficies. Comprueba en tu tenant qué está en preview y qué no.

SuperficieCómo funciona
PowerPointSkills personales en OneDrive. Se invocan por nombre o desde Choose skills.
ExcelSkills para usuarios finales y una preview para desarrolladores.
CoworkSkills integradas, personales y empaquetadas · Customize · Skills.
