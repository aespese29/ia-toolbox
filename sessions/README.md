## 📥 Descargar materiales

Dentro de cada carpeta de sesión encontrarás:
- **Presentación PDF** para consultar
- **Imagen de portada** de referencia
- **README.md** con resumen y detalles del ponente

---

## 🎤 Eres ponente y quieres compartir tu sesión?

Crea una carpeta con el nombre de tu sesión (minúsculas y guiones) y añade:
1. `README.md` → resumen, contenido, ponente y contacto
2. `presentacion.pdf` → archivo de la sesión
3. `cover.jpg` o `cover.png` → imagen de portada

Luego envíanos el enlace a **aespes@adrianespes.com**.
