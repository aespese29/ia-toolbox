# Building useful agents with Copilot Studio Lite

[Spanish](README.md) · [English](README.en.md)

![Building useful agents with Copilot Studio Lite](cover.jpg)

Session delivered at **AgentCamp Valencia 2026** (March 7, 2026, ESIC Valencia) about building genuinely useful agents with Copilot Studio Lite, based on real-world cases and without writing a single line of code.

## Content

- What is an agent? Assistant vs. Agent
- Technologies and options for building agents
- Anatomy of a declarative agent: Agent Builder vs. Copilot Studio
- When is each one the right fit?
- Logical reasoning for building agents: what to avoid and how to think
- How do I get from input to output?
- Demo: a Microsoft 365 Copilot adoption agent
- Tips and tricks to improve your agent
