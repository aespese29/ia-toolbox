# Copilot Control System: governance and configuration from the Microsoft Admin Center

[Spanish](README.md) · [English](README.en.md)

![Copilot Control System: governance and configuration from the Microsoft Admin Center](cover.jpg)

Session delivered at **Tenerife Winter Sessions 2026** about moving from "just turning Copilot on" to governing it in a secure, scalable, and outcome-driven way from the Microsoft Admin Center.

## Content

- The day the CIO asked: who really controls Copilot?
- Copilot without governance vs. Copilot with Copilot Control System
- What does Copilot really control? Context, data, and entry points
- Access point configuration, protection, and privacy
- Copilot in Edge, web search, and third-party AI providers
- Who can do what? Users, roles, image generation, and agent usage
- Risk and cost: pay-as-you-go and usage reports
- Secure and scalable deployment: phases and best practices
