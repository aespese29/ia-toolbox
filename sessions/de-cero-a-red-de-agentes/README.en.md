# From zero to a network of agents: Copilot Studio Lite vs Full

[Spanish](README.md) · [English](README.en.md)

![From zero to a network of agents: Copilot Studio Lite vs Full](cover.jpg)

Session delivered at **AgentCamp Barcelona 2026** (March 14, 2026, Harbour Space University) about when to choose Copilot Studio Lite or Full, and how to move from a single agent to a network of collaborating agents.

## Content

- What is an agent? Core concepts
- Options for building agents: which one should I choose?
- Anatomy of a declarative agent: Microsoft 365 Agent Builder vs. Copilot Studio
- When is each one the right fit? Decision criteria
- Logical reasoning for building agents: what to avoid and how to think
- How do I get from input to output? Components in Copilot Studio
- Clarifying models in Copilot Studio Full
- Hands-on case: a network of agents for event management
