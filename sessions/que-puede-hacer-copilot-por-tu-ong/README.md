# ¿Qué puede hacer Copilot por tu ONG?

[Español](README.md) · [English](README.en.md)

![¿Qué puede hacer Copilot por tu ONG?](cover.jpg)

Sesión dirigida a organizaciones sin ánimo de lucro sobre cómo Microsoft Copilot ayuda a optimizar recursos y aumentar el impacto social, liberando tiempo para lo que realmente importa.

## Contenido

- ¿Qué es Microsoft Copilot?
- Copilot como IA para potenciar el impacto social
- Beneficios clave para tu ONG
- Caso de uso: gestión y comunicación de resultados de proyectos sociales
- Redacción del informe mensual a partir de notas y resúmenes de actividad
- Análisis y visualización de datos de donaciones e impacto
- Preparación de la presentación para patronato y donantes
- Consideraciones clave para un uso responsable y limitaciones de Copilot
