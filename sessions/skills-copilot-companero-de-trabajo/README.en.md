# How Skills turn Copilot into a real coworker

[Spanish](README.md) · [English](README.en.md)

Session delivered at **Cloud Champion** (October 21, 2026) about Microsoft 365 Copilot Skills: from prompts to productivity. How to package your working method into a reusable capability instead of rewriting the same 40-line prompt every week.

## Content

- The starting point: the long prompt you copy, paste, and tweak every Monday
- Prompt, agent, and Skill: how they differ and when to use each one
- Anatomy of a Skill: one folder, one `SKILL.md`, YAML frontmatter, and optional resources
- Where Skills live today: PowerPoint, Excel, Cowork, and Agent Builder
- Demo 01 · The "before": the prompt that explains everything (Copilot Chat)
- Demo 02 · My first personal Skill in PowerPoint (PowerPoint web + OneDrive)
- Demo 03 · Creating a Skill just by talking (Agent Builder)
- Demo 04 · One agent, several Skills (ZIP packages in Agent Builder)
- Demo 05 · Delegating work with your own method (Cowork)
- Before and after: from prompt to capability
- Use cases to get started on Monday
- Best practices and governance: scaling without losing control

## Available material

- Session presentation (PDF, in Spanish)
- Demo kit (`kit-demos/`): demo guide, fictional brief, project status document, the `resumen-ejecutivo-comite` skill, and the `kit-anuncio-evento.zip` and `faq-evento.zip` packages

> All demo data is fictional.
