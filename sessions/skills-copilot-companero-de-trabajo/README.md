# Cómo las Skills convierten Copilot en un verdadero compañero de trabajo

[Español](README.md) · [English](README.en.md)

Sesión presentada en **Cloud Champion** (21 de octubre de 2026) sobre las Skills de Microsoft 365 Copilot: de los prompts a la productividad. Cómo empaquetar tu método de trabajo en una capacidad reutilizable en lugar de reescribir el mismo prompt de 40 líneas cada semana.

## Contenido

- El punto de partida: el prompt largo que copias, pegas y ajustas cada lunes
- Prompt, agente y Skill: en qué se diferencian y cuándo usar cada uno
- Anatomía de una Skill: una carpeta, un `SKILL.md`, frontmatter YAML y recursos opcionales
- Dónde viven hoy las Skills: PowerPoint, Excel, Cowork y Agent Builder
- Demo 01 · El antes: el prompt que lo explica todo (Copilot Chat)
- Demo 02 · Mi primera Skill personal en PowerPoint (PowerPoint web + OneDrive)
- Demo 03 · Crear una Skill solo hablando (Agent Builder)
- Demo 04 · Un agente, varias Skills (paquetes ZIP en Agent Builder)
- Demo 05 · Delegar el trabajo con tu método (Cowork)
- Antes y después: del prompt a la capacidad
- Casos de uso para empezar el lunes
- Buenas prácticas y gobernanza: escalar sin perder el control

## Material disponible

- Presentación de la sesión (PDF)
- Kit de demos (`kit-demos/`): guía de demos, brief ficticio, documento de estado de proyecto, la skill `resumen-ejecutivo-comite` y los paquetes `kit-anuncio-evento.zip` y `faq-evento.zip`

> Todos los datos de las demos son ficticios.
